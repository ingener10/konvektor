Политика конфиденциальности

Последнее обновление: 15 ноября 2026 года

1. О сайте

Сайт mykonvektor.ru (далее «Сайт») — бесплатный инструмент для преобразования изображений и документов (Блокнот, Word, PDF) из одного формата в другой. Связаться с владельцем Сайта можно по адресу sasha3561@list.ru.

2. Ваши файлы

Преобразование выполняется в вашем браузере, на вашем устройстве. Изображения, документы и тексты, которые вы выбираете на Сайте, не отправляются на сервер Сайта, не сохраняются и не просматриваются владельцем.

Единственное исключение: чтобы прочитать PDF-файл, браузер один раз загружает библиотеку чтения PDF (pdf.js) с сервиса jsDelivr (cdn.jsdelivr.net). Содержимое вашего файла при этом никуда не передаётся, но сервис jsDelivr, как и любой сайт, получает технические данные запроса: IP-адрес и сведения о браузере.

3. Какие данные могут собираться автоматически

  • Хостинг. Сайт размещён на GitHub Pages. Как поставщик хостинга, GitHub может получать технические данные посещения (IP-адрес, сведения о браузере, время запроса) в соответствии со своей политикой конфиденциальности.
  • Статистика. Сайт использует или может использовать сервис Яндекс Метрика. Он собирает обезличенную статистику посещений: какие страницы открывают, с какого устройства и по какой ссылке пришли. Для этого могут использоваться файлы cookie.
  • Реклама. Сайт использует или может использовать Рекламную сеть Яндекса. Для показа рекламы Яндекс может использовать файлы cookie и похожие технологии, в том числе на основе интересов посетителя. Подробнее: политика конфиденциальности Яндекса.

4. Файлы cookie

Cookie — небольшие файлы, которые сохраняются в вашем браузере. Вы можете запретить или удалить их в настройках браузера. Преобразование файлов на Сайте от этого работать не перестанет.

5. Передача данных третьим лицам

Владелец Сайта сам не собирает персональные данные посетителей и никому их не передаёт. Данные, перечисленные в разделе 3, получают перечисленные там сервисы на условиях их собственных политик.

6. Обратная связь

Если у вас есть вопросы по этой политике или вы хотите, чтобы мы учли ваше обращение, напишите на sasha3561@list.ru.

7. Изменения

Политика может обновляться. Актуальная версия всегда находится на этой странице, дата последнего обновления указана вверху.
